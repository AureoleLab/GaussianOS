# ADR P1: production reconstruction and Gaussian training chain

- Date: 2026-07-12
- Status: **technical selection accepted; P1 WAITING_FOR_REFERENCE; P2 blocked**
- Dataset: `sha256:152be2c9901a8652daa032ab5c35a65aaf3aa83fc1deb1a1afa41a2a2a3ab33d`

## Decision

Select this production chain:

1. FFmpeg ingestion and immutable keyframes.
2. COLMAP 3.13.0 as the default reconstruction.
3. gsplat 1.5.3 as the default Gaussian trainer.
4. When a deterministic COLMAP quality gate fails, MapAnything Apache v1.1.2
   performs inference, exports a COLMAP 3.13 model, and COLMAP bundle adjustment
   refines it.
5. SceneBundle v1 remains the internal truth; `*.graphdeco-gs-v1.ply` is an
   export/import format validated by ExportKit, gsply, SplatTransform, and Brush.

This resolves the production reconstruction, trainer, and automatic fallback
choices. Faster-GS is not selected because it has not been run. GLUEMAP,
VGGT-Omega, and ImprovedGS remain research-only and production policy denies
them.

P1 is `WAITING_FOR_REFERENCE`, not GO: Postshot and legacy COLMAP+Brush
fixed-camera references are absent. P2 must not start until those are imported
and the visual/UX gap is scored.

## Verified architecture

The P1 Worker and SceneBundle architecture from commit `4c6df3a…` is unchanged:

- host code launches versioned JSON Workers in separate process groups;
- each attempt has isolated work/output/log/cancellation paths;
- crashes, CUDA OOM, timeout, and cancellation cannot crash the host;
- workers cannot access a project database;
- artifact files are hash/size/set validated before atomic publication;
- production and research profile locks fail closed;
- cameras are OpenCV cam2world, +X right, +Y down, +Z forward;
- Gaussian data uses float32 means, log scales, wxyz quaternions, opacity
  logits, and degree-major real SH coefficients.

No Qt, GUI, API, or other P2 work is included.

## gsplat validation

gsplat is fixed to v1.5.3 / `937e29912570c372bed6747a5c9bf85fed877bae`.
The private Windows build used:

- Visual Studio Build Tools 2022 17.14.35, cl 19.44.35228;
- CUDA nvcc 13.0.48 and `CUDA_HOME` at the private CUDA 13 prefix;
- CMake 3.31.6-msvc6, Ninja 1.12.1;
- Python 3.10.20, PyTorch 2.9.1+cu130;
- `TORCH_CUDA_ARCH_LIST=12.0`.

`gsplat/csrc.pyd` SHA-256 is
`846115e6db8b4862d4f050b4bc9eec45b111de8946529352bb5af5272c0e53bf`.
Real forward/backward on RTX 5090 produced finite renders and nonzero gradients
for every parameter group. The three formal runs used 7000 steps with real
DefaultStrategy densification; they were not mocks or one-iteration probes.

appearance, not blind pose localization. This distinction must remain in later
benchmark comparisons.

## MapAnything fallback validation

MapAnything is fixed to v1.1.2 / `c845b8f4f6cde0c20aecd87573656c3f69f5b2b0`.
The Apache checkpoint is exactly 4,914,062,480 bytes / SHA-256 `fa06c0fd…`.
The upstream model also requires DINOv2 ViT-g/14; that dependency is now
explicitly locked to commit `7764ea0…`, 4,546,108,579 bytes / SHA-256
`baf8467e…`, Apache-2.0. UniCeption 0.1.7, Open3D 0.19.0, pycolmap 3.13.0,
and their source commits are production profile locks.

The hard case is deterministic but retains real scene content: 12 frozen
scene-001 frames resized to 256×144, blurred, contrast-reduced, and alternately
exposed. Direct COLMAP produced zero matches and no reconstruction. MapAnything
then recovered 12 cameras and the 3.13 adapter retained 7,989 points with at
least two observations. COLMAP BA processed 101,416 residuals / 24,056
parameters and converged in 5 iterations, reducing cost from `4.63955e-6` to
`2.6784e-7` px. The output has mean track length 6.347227 and canonical
CameraTensors validation passed.

The upstream exporter assumes pycolmap 3.10. A Worker-owned adapter supplies
COLMAP 3.13 Rig/Frame registration and removes single-view points before BA;
third-party source is untouched. Reconstruction-stage validation intentionally
covers the SceneBundle camera payload only and does not pretend that a trainer
ran on the fallback artifact.

Normal-scene gating was also run: scene 001 registered 39/39 after an isolated
retry of a transient mapper crash. The Worker returned `POLICY_DENIED` before
loading MapAnything. Mapper crashes that are not the deterministic “no matches”
failure are no longer misclassified as low reconstruction quality.

## Postshot and legacy gap

No Postshot or old COLMAP+Brush reference was found. Import placeholders and
required manifests are in `benchmarks/references`. No candidate render or
metric was relabeled as a reference.

Candidate-only inspection found mild/moderate distant softness in scene 001,
severe skyline tearing/ghost structures in scene 002, and comparatively strong
structure/color with some highlight blur in scene 003. Without byte-identified
reference renders, quality, runtime, memory, UX, and artifact deltas versus
Postshot or the old workflow remain N/A.

## Remaining risks

1. Postshot and legacy reference comparisons are unavailable; P1/P2 stay gated.
2. Scene 002 has obvious visual tearing despite strong aggregate metrics.
3. MapAnything export observations are projection-derived, so analyzer residuals
   are near zero; BA execution is proven by precise Ceres costs, not by the
   rounded analyzer value.
4. MapAnything fallback CameraTensors pass, but a full fallback → gsplat training
   run was outside this round's requested chain.
5. Faster-GS is still unexecuted, and research candidates remain intentionally
   excluded from production.
