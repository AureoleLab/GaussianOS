# Contributing

GaussianOS is Alpha software. Please discuss substantial changes in an issue
before submitting a pull request. Do not commit model weights, runtimes,
project data, benchmark evidence, videos, generated PLY/SceneBundle files,
credentials, or local configuration. Run `uv run pytest` before opening a PR.

Production changes must preserve the locked versions, hashes, and licenses in
the runtime manifest and must not enable research-only workers.
